# Hotel Booking App

## 1. Project Description

Hotel Booking App is a simple application that helps users find
hotels and book rooms easily.

The goal of this project is to make hotel reservations easier
and save time for users.

Users can view available hotels, choose a hotel, select a room,
and make a booking.

## 2. Project Objectives

- Help users find hotels.
- Allow users to choose a room.
- Make the booking process simple.
- Organize hotel and reservation information.
- Provide an easy way to manage bookings.

## 3. Main Features

- View the list of hotels.
- Choose a hotel.
- Select a room.
- Enter customer information.
- Confirm a reservation.
- View booking information.

## 4. How to Use the Application

1. Open the application.
2. View the available hotels.
3. Choose a hotel.
4. Select a room.
5. Enter your personal information.
6. Confirm the reservation.
7. Check the booking information.

## 5. Project Structure

The project is organized into different files and folders.

- README.md: Contains information about the project.
- src/: Contains the source code.
- src/main.py: Contains the main program.
- tests/: Contains tests to check the application.

## 6. Technologies Used

- Python: To develop the application.
- Git: To manage the project and track changes.
- GitHub: To store and share the project online.

## 7. Future Improvements

In the future, the application can include:

- User registration and login.
- Hotel search by city.
- Room prices and availability.
- Booking cancellation.
- Online payment.

## 8. Conclusion

This project is a simple hotel booking application.
It helps users find hotels and reserve rooms easily.
It is also an opportunity to learn programming,
project organization, and version control using Git.
